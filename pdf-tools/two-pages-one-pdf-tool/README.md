# Two Pages to One PDF

The shared PDF tools server serves this tool at `http://max-nas:4888/two-pages-one-pdf-tool/`. It lets you select two pages, draw independent crop regions, choose Letter/A4 or source page size, and compose the result locally in the browser.

To run it standalone, use `npm install` and `npm start`; the server listens on port 4891 by default.
